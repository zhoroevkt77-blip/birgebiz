# БИРГЕБИЗ

Россиядагы кыргыз мекендештер жана эмгек мигранттары үчүн бекер жарыя тактасы.
14 категория, 32 шаар, 25 шаардын райондору, аккаунтсуз жарыя берүү, шикаят жана модерация.

## Түзүлүшү

| Файл | Эмне кылат |
|---|---|
| `app.py` | FastAPI сервер: `/api/ads` (тизме, кошуу, өчүрүү, шикаят), базаны өзү түзөт |
| `static/index.html` | Сайттын өзү (бир файл, PWA) |
| `static/sw.js`, `manifest.webmanifest` | Телефонго орнотуу жана офлайн ачылуу |
| `railway.json` | Railway баштоо буйругу жана healthcheck |

## Railway'ге чыгаруу

1. GitHub'та `birgebiz` репосун ачып, ушул файлдарды push кылыңыз.
2. Railway → **New Project → Deploy from GitHub repo** → `birgebiz`.
3. Ошол эле проектке **+ New → Database → PostgreSQL** кошуңуз.
4. `birgebiz` сервисинин **Variables** бөлүмүнө:
   - `DATABASE_URL` = `${{Postgres.DATABASE_URL}}` (Reference катары тандаңыз)
   - `ADMIN_TOKEN` = узун жашыруун сөз (мис. 32 белги)
   - `HASH_SALT` = каалаган башка жашыруун сөз
5. **Settings → Networking → Generate Domain**. Сайт ачылат, таблицалар өзү түзүлөт.

## Модерация

Телефондон бир жолу ачыңыз: `https://<домен>/?admin=<ADMIN_TOKEN>`.
Токен браузерде сакталат, URL'ден өчүрүлөт. Андан кийин:
- каалаган жарыяда **«Модерация: өчүрүү»** баскычы чыгат;
- 3 шикаят алган жарыялар бардыгынан жашырылат, сизге «Жашырылган» белгиси менен көрүнөт — **«Кайра ачуу»** же өчүрүү.

Админ режимден чыгуу: `/?admin=`

## Эрежелер жана лимиттер (`app.py` башында)

- `REPORTS_TO_HIDE = 3` — ушунча шикаяттан кийин жашырылат
- `MAX_ACTIVE_PER_OWNER = 30` — бир адамга активдүү жарыя
- `MAX_POSTS_PER_IP_HOUR = 6` — спамга каршы
- `AD_LIFETIME_DAYS = 60` — жарыя 60 күндөн кийин тизмеден чыгат

## Жарыянын ээси кантип аныкталат

Аккаунт жок. Ар бир браузер биринчи кирүүдө жашыруун токен түзөт (`localStorage`).
Базада токендин хэши гана сакталат. Ошол браузерден гана өз жарыяңызды өчүрө аласыз.
Браузердин маалыматын тазаласаңыз, эски жарыяларды админ өчүрөт.

## Жергиликтүү иштетүү

```bash
pip install -r requirements.txt
export DATABASE_URL=postgresql://user:pass@localhost:5432/birgebiz
export ADMIN_TOKEN=test-admin-token
uvicorn app:app --reload --port 8080
```
