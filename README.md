# БИЗ БИРГЕБИЗ!

Россиядагы кыргыз мекендештер жана эмгек мигранттары үчүн бекер жарыя тактасы.
14 категория, 32 шаар, 25 шаардын райондору, аккаунтсуз жарыя берүү, «шектүү деп кабарлоо» жана модерация.

## Түзүлүшү

| Файл | Эмне кылат |
|---|---|
| `app.py` | FastAPI сервер: `/api/ads` (тизме, кошуу, өчүрүү, кабарлоо), базаны өзү түзөт |
| `static/index.html` | Сайттын өзү (бир файл, PWA) |
| `static/sw.js`, `manifest.webmanifest` | Телефонго орнотуу жана офлайн ачылуу |
| `railway.json` | Railway баштоо буйругу жана healthcheck |

## Railway'ге чыгаруу

1. GitHub'та `birgebiz` репосун ачып, ушул файлдарды push кылыңыз.
2. Railway → **New Project → Deploy from GitHub repo** → `birgebiz`.
3. Ошол эле проектке **+ New → Database → PostgreSQL** кошуңуз.
4. `birgebiz` сервисинин **Variables** бөлүмүнө:
   - `DATABASE_URL` = `${{Postgres.DATABASE_URL}}` (Reference катары тандаңыз)
   - `ADMIN_TOKEN` = узун жашыруун сөз (мис. 32 белги)
   - `HASH_SALT` = каалаган башка жашыруун сөз
5. **Settings → Networking → Generate Domain**. Сайт ачылат, таблицалар өзү түзүлөт.

## Админ панель

Каалаган браузерден: `https://<домен>/admin` → `ADMIN_TOKEN` жазып «Кирүү». Жалпы колдонуучуларга кирүү баскычы көрүнбөйт.

| Өтмөк | Эмне бар |
|---|---|
| Статистика | Жалпы / активдүү / бүгүн / мөөнөтү бүткөн жарыялар, шектүү, көрүүлөр, колдонуучулар, сүрөттүү, бөгөттөлгөн, төлөм, киреше; категория жана шаар боюнча. Плитканы бассаңыз, ошол жарыялар ачылат |
| Жарыялар | Бардык жарыялар (мөөнөтү бүткөндөр да): издөө, фильтр, категория, өчүрүү, ээсин көрүү |
| Модерация | Төлөм чектерин тастыктоо / четке кагуу; 3 «шектүү» кабар алып жашырылгандарды кайра ачуу же өчүрүү |
| Колдонуучулар | Телефон (WhatsApp / Telegram) боюнча: жарыя саны, көрүү, бекер лимит; **бөгөттөө** — анын жарыялары жашырылат, жаңы жарыя бере албайт |
| Курс | Которуу сервистерин кошуу / өзгөртүү / өчүрүү |
| Билдирүү | Башкы беттин башында бардыгына көрүнгөн кабар (маалымат / эскертүү / жакшы кабар) |

## Акы алуу (алгачкы 10 жарыя бекер)

Баалар `pricing.py` файлында:

| Деңгээл | Баасы | Категориялар |
|---|---|---|
| Дайыма бекер | 0 ₽ | Кайрымдуулук, Жумуш издөө, Барахолка → «Бекер берем» |
| Жеке адамдар | 50 ₽ | Барахолка; «Кыргызстанга кайтам», «Россияга барам»; «Батир / койка издейм»; Авто → «Сатып алам», «Ижарага алам» |
| Кадимки | 100 ₽ | Жумуш берүү, Туракжай, Посылка, Жүргүнчү ташуу, Тамак-аш, Сулуулук, Билим, Оңдоо |
| Бизнес | 200 ₽ | Юридикалык, Авиакасса, Медицина, Авто кызмат, Автоунаа |

- Бекер лимит бир **телефон номерине** (же WhatsApp / Telegram) эсептелет: `FREE_LIMIT = 10`.
- **Төлөмдү күйгүзүү:** Railway → Variables → `PAY_INFO` = реквизиттер (бир нече сап болот), мис.:
  `СБП: +7 900 000-00-00 (Т-Банк)` / `MBank: 0700 000 000`
- `PAY_INFO` бош болсо — акы алуу өчүк, бардык жарыялар бекер, бирок эсеп жүрө берет.
- Лимит бүткөндө колдонуучу чектин скриншотун жүктөйт, жарыя «Төлөм текшерилүүдө» абалында турат.
  Админ: Кабинет → **Төлөмдөрдү текшерүү** → Тастыктоо / Четке кагуу. **Статистика** да ошол жерде.

## Сүрөттөр

- Жарыяга 5 сүрөткө чейин (милдеттүү эмес). Телефондо 1280 px'ке кичирейтилип, базага (`ad_photos`) сакталат.
- Тизмеде башкы сүрөттүн кичине нускасы (`ads.thumb`, 360 px) көрүнөт.
- Жарыя өчүрүлсө, сүрөттөрү да өчөт.

## Которуу сервистеринин курсу

- Курс терезесинде (башкы беттеги «Курс ›») — «Которуу сервистеринин курсу».
- Админ гана кошот/өзгөртөт: аты, «1000 ₽ үчүн канча сом», комиссия, кошумча, байланыш.
- 48 сааттан ашык жаңыртылбаган курс «эскирген болушу мүмкүн» деп белгиленет.

## Эрежелер жана лимиттер (`app.py` башында)

- `REPORTS_TO_HIDE = 3` — ушунча кабардан кийин жашырылат
- `MAX_ACTIVE_PER_OWNER = 30` — бир адамга активдүү жарыя
- `MAX_POSTS_PER_IP_HOUR = 6` — спамга каршы
- `AD_LIFETIME_DAYS = 60` — жарыя 60 күндөн кийин тизмеден чыгат

## Жарыянын ээси кантип аныкталат

Аккаунт жок. Ар бир браузер биринчи кирүүдө жашыруун токен түзөт (`localStorage`).
Базада токендин хэши гана сакталат. Ошол браузерден гана өз жарыяңызды өчүрө аласыз.
Браузердин маалыматын тазаласаңыз, эски жарыяларды админ өчүрөт.

## Жергиликтүү иштетүү

```bash
pip install -r requirements.txt
export DATABASE_URL=postgresql://user:pass@localhost:5432/birgebiz
export ADMIN_TOKEN=test-admin-token
uvicorn app:app --reload --port 8080
```
